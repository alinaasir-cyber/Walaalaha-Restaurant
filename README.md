# Walaalaha Restaurant - Enterprise ERP & POS System

Complete Enterprise Restaurant, Event Hall, Kitchen Inventory, Accounting, and HR Management System for **Walaalaha Restaurant**, built with **Next.js 15**, **TypeScript**, and **Tailwind CSS**.

## Features & Modules

- **Executive Financial Dashboard:** Total Assets, Liabilities, Capital, Revenue, Expenses, Net Income, and Monthly Sales Performance Bar Chart.
- **POS Management:**
  - Real-time POS Dashboard with Floor & Table status.
  - Interactive Touch Menu Ordering (`/pos/menu`) with Somali & English food items.
  - Live Kitchen Orders Screen (KDS / KOT).
  - Cashier Sessions, Waiter tracking, Bulk Payments, and Transfer Records.
- **Services POS:** Special catering services, VIP rooms, sound systems, and hourly rentals.
- **Inventory Management:** Vendors, Raw Food Purchases, Stock Adjustments, A/P Aging, and Payment Plans.
- **Hall & Event Management:** Banquet halls, wedding schedules, event waitstaff, and profitability tracking.
- **Store & Kitchen Stock:** Kitchen transfers, daily usage logging, and waste control.
- **Accounting & Budgets:** Double-entry Chart of Accounts, Journal Entries, Financial Statements, Cash Reconciliation, and Budgets.
- **Fixed Assets & Expenses:** Asset Register, Depreciation, Maintenance, and Daily Expenses.
- **HR & Payroll:** Staff directory, Shifts, Attendance, Leaves, Overtime, and Payroll Slips.
- **Administration & Security:** Users, Roles, Permissions, and Multi-Branch Setup.

## Tech Stack

- **Framework:** Next.js 15 (React 19, App Router)
- **Styling:** Tailwind CSS (Modern White & Soft Rose/Red Theme)
- **Icons:** Lucide React
- **Language:** TypeScript

## Getting Started

```bash
# Install dependencies
npm install

# Run the development server
npm run dev

# Build for production
npm run build
```

Open [http://localhost:3000](http://localhost:3000) with your browser.
